# Binärgewitter Blog

The official blog for the [Binärgewitter](https://blog.binaergewitter.de/) podcast, built with [Hugo](https://gohugo.io/).

## Features

- **Plain Hugo build**: no npm or JS build step; feeds, search index and statistics are all generated by Hugo templates
- **Podcast feeds**: RSS feeds for every category (`all`, `talk`, `spezial`, `westcoast`) and codec (`mp3`, `ogg`, `opus`, `m4a`), with chapters, transcripts (JSON and WebVTT) and funding tags
- **Podlove Web Player**: self-hosted, with chapters and contributors
- **Transcripts**: every episode with audio links its transcript, on the episode page and in the feeds
- **Search**: client-side FlexSearch with German language settings; the index is served precompressed (Brotli, gzip fallback) and also exposes episode metadata for machines
- **Sprechzeit** (`/sprechzeit/`): who talked how long, per episode, person and year, plus a full-text search over the transcripts; computed from the transcripts at build time
- **Structured data**: JSON-LD for episodes and the site, OpenGraph/Twitter tags
- **Comments**: [Isso](https://isso-comments.de/) at `comments.binaergewitter.de`
- **Live indicator**: shows when the stream is on air
- **Fly.io deployment**: Docker image with nginx, deployed by GitHub Actions on every push to `main` and nightly

## Development

### Prerequisites

- [Hugo](https://gohugo.io/installation/) v0.154.2 (extended), the version CI and the Dockerfile use
- Node.js to run the tests
- Python 3 for the new-episode script (optional)

### Local Development

```bash
# Start the development server
hugo server

# Build the site
hugo --minify

# Run the tests (needs a build in public/)
gzip -k public/index.json
node tests/test.js
```

The site will be available at `http://localhost:1313/`.

The first build downloads all episode transcripts from `download.binaergewitter.de` for the Sprechzeit statistics and needs about 1.2 GB of memory. Downloads are cached for 24 hours.

### Creating New Episodes

```bash
articles/scripts/new_episode.py 2026-11-10.Binaergewitter.Talk.389 --posts-dir articles
```

The script starts from the newest post and fills in title, description, audio files, chapters and transcript from the download server, and the shownotes from the Etherpad (login via `ETHERPAD_USER`/`ETHERPAD_PASSWORD` or `~/.netrc`). See `--help` for all options.

For other posts, `hugo new post/YYYY-MM-DD-your-post-title.md` uses the archetype in `archetypes/post.md`.

## Project Structure

```
.
├── articles/            # Blog posts and episodes (mounted as content/post)
│   └── scripts/         # new_episode.py
├── pages/               # Static pages (mounted as content/pages)
├── content/
│   ├── podcast_feed/    # Feed pages generated by _content.gotmpl
│   ├── sprechzeit.md
│   └── archives.md
├── data/sprechzeit.yaml # Speaker aliases and search terms for Sprechzeit
├── layouts/             # Hugo templates
│   ├── _default/        # Base, list, single, RSS and feed templates
│   ├── partials/        # Reusable components (player, search, schema, …)
│   ├── index.json       # Search index
│   └── index.latestshow # /latest-show (number of the newest episode)
├── assets/              # Fingerprinted CSS/JS (Sprechzeit)
├── static/              # Static assets (CSS, JS, images, Podlove player)
├── archetypes/          # Content templates
├── tests/test.js        # Site tests, run in CI
├── Dockerfile           # Hugo build + nginx image
├── nginx.conf
└── fly.toml
```

## Deployment

GitHub Actions builds and tests every push and pull request. Pushes to `main` deploy to Fly.io, and a nightly build at 04:17 UTC redeploys so the Sprechzeit numbers pick up corrected transcripts. Pull requests get desktop and mobile screenshots of the front page as a comment.

### Manual Deployment

```bash
flyctl deploy
```
